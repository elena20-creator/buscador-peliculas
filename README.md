# api-peliculas

Proyecto que usa la API de TMDB para buscar películas y ver las populares. Muestra el póster, el título, el año y la sinopsis de cada una.

## Pasos para correrlo

1. `pnpm install`
2. Crear un archivo `.env` con `VITE_TMDB_API_KEY=` y la llave de TMDB (hay un ejemplo en `.env.example`).
3. `pnpm dev`
4. Abrir `http://localhost:5173` en el navegador.
